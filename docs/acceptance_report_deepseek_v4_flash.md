## 三、独立发现的残余问题

> 严重度：🔴 阻断 / 🟠 中 / 🟡 轻 / ⚪ 提示

- **F1 🟠（HIM+DL 措辞）**：外挂 MLP 的训练标签是 `env.step` 返回的**内在舒适度信号** `c`，并非 HIM 学到的 `V` 记忆。因此"仅在 HIM 自涌现表示上训练"的措辞**不够精确**；准确说法是"采样在 HIM 自主探索轨迹上，标签为该轨迹的内在舒适度信号"。**不构成作弊**（内在信号、无外部任务/标注），但建议收紧措辞。
- **F2 🟠（HIM+DL 缺对照）**：未证明 HIM 的**定向探索**比随机探索更能产出对 DL 有用的数据——缺少"同预算随机采集数据训练 DL"的对照。建议补该对照以坐实"协作增益"。
- **F3 🟡（HIM+DL 表述）**：corr 0.565 下称 "recovers the comfort field" 略强，建议保留"学到场的方向"的软化表述。
- **F4 🟡（Track A 表述）**：跨世界"场景辨认" corr 0.799 仅在**已访问场景**上测得（`value_transfer_corr_unseen = null`，未访问集为空）；因舒适度本身世界无关，该测试实际证明的是"V 世界无关"，而非"对全新场景的泛化"。措辞可更精确。
- **F5 ⚪（附录·提示）**：附录 A.1 命令 (1) 会命中含 "torch" 的注释行；论文已注明"matches only comments"，但严格读者仍可能误读，建议在命令中过滤注释。
- **F6 🟡（论文内部不一致）——已由验收方修复**：§6 正文写 "Ashby's homeostat (1948)"、"Grey Walter's tortoises (1948)"，而参考文献已修为 1952/1953——上一轮 P2 修了引用漏改正文。**已改正文为 1952/1953 并重同步云端。**
