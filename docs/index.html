自涌现因果链 The comfort-gradient loop

闭环即智能：运动改变感官状态 → 与需求态的重叠率产生舒适度 → 被动记住「(运动,互动)→感官变化→舒适度」 → 据此识别场景、决策以维持/提升舒适度（趋利避害）。舒适度的时间梯度 ΔLₜ 即唯一的内生奖励。

红线（方法学约束） Red lines — what CIT-K is NOT allowed to use

  • R1 最底层（感官-运动闭环→舒适度→被动因果记忆）不可替换
  • R2 仅「身体」与「感官需求如何塑造记忆需求」可调；记忆需求态从不被直接设定
  • R3 需求态必须自涌现，不被指派
  • R4 不引入任何竞争理论：无 RL 奖励、无自由能目标、无外部目标
  • R5 外部数学只回答「是什么」，不回答「要什么」
  • R6 无神经网络、无预训练、无梯度、无逐游戏分支
  • R7 感知只回答「是什么」，不回答「要什么」

架构性免疫奖励黑客：因 R4 不接纳任何奖励信号，智能体没有可供优化的目标， 奖励黑客这一失效模式在架构层面结构性缺席——不是靠更好的奖励塑形规避。
